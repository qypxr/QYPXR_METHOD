# QYPXR METHOD

Оптимизатор видео для TikTok с красивым интерфейсом. Перетащи видео, выбери целевой FPS (по умолчанию 400) и нажми «Оптимизировать». Программа перестраивает структуру MP4/MOV-файла, без перекодирования.

## Возможности
- Поддержка MP4 и MOV
- Перетаскивание файла мышкой или выбор через встроенный проводник
- Настраиваемый целевой FPS
- Список готовых файлов с кнопкой «В папке»
- Несколько цветовых тем

## Как пользоваться
1. Выбери или перетащи MP4/MOV файл.
2. Задай целевой FPS (по умолчанию 400).
3. Нажми «Оптимизировать».

## Сборка
Нужны Windows и Visual Studio (C++, Desktop development).
1. Открой `QYPXR_METHOD.vcxproj`.
2. Выбери конфигурацию `x64` / `Release`.
3. Собери проект (Ctrl+Shift+B).
